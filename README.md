# Learning Log

Веб-приложение на базе **Django** для ведения дневника обучения: создания тем и добавления записей по мере изучения нового материала.

> **Примечание:** Содержимое внутренних конфигурационных файлов репозитория (`compose.yaml`, `Dockerfile`, `.env-example`, `requirements.txt`) недоступно для прямого чтения, поэтому инструкция составлена на основе структуры файлов проекта (`manage.py`, `compose.yaml`, `.env-example`, `requirements.txt`). Перед запуском проверьте актуальные имена переменных и порты в вашем репозитории.

---

## Вариант 1: Запуск через Docker Compose (рекомендуемый)

В проекте присутствуют `Dockerfile` и `compose.yaml`, что позволяет развернуть приложение в контейнерах.

1. **Клонируйте репозиторий:**

2. **Настройте переменные окружения:**
   Создайте файл `.env` на основе шаблона `.env-example` и при необходимости отредактируйте значения (например, `SECRET_KEY`, `DEBUG`, параметры БД):
   ```bash
   cp .env-example .env
   ```

3. **Соберите и запустите контейнеры:**
   ```bash
   docker compose up --build
   ```

4. **Примените миграции базы данных** (если они не выполняются автоматически при старте контейнера):
   ```bash
   docker compose exec web python manage.py migrate
   ```
   *(Уточните имя сервиса в `compose.yaml` — обычно `web` или `app`).*

5. **Откройте приложение в браузере:**
   Перейдите по адресу `http://localhost:8000` (или другому порту, указанному в `compose.yaml`).

## Вариант 2: Локальный запуск (Python + venv)

Если вы хотите запустить проект без Docker:

1. **Клонируйте репозиторий и перейдите в папку проекта:**

2. **Создайте и активируйте виртуальное окружение:**
   * **Linux / macOS:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   * **Windows:**
     ```bash
     python -m venv venv
     venv\Scripts\activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   ```bash
   cp .env-example .env
   ```
   Откройте `.env` и заполните необходимые настройки.

5. **Выполните миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

6. **(Опционально) Создайте суперпользователя для доступа в админ-панель:**
   ```bash
   python manage.py createsuperuser
   ```

7. **Запустите сервер разработки:**
   ```bash
   python manage.py runserver
   ```

8. **Откройте приложение в браузере:**
   * Основной сайт: `http://127.0.0`
   * Панель администратора: `http://127.0.0/admin/`
